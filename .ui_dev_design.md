# EcosystemSim Scenario UI Design

## Purpose

Let the player start either an unrestricted ecosystem sandbox or a constrained challenge, then
shape the simulation while understanding whether their interventions are moving the ecosystem
toward the goal.

## Hero Flow

The player spends most of the session watching the hex map, selecting stressed tiles, and applying
limited interventions while monitoring challenge progress.

## Hero Surface

The map remains the largest surface. Scenario status and objectives stay visible in a compact
top-right panel. Tile-specific interventions appear beside the selected tile details so the player
never has to re-enter coordinates or species names.

## Known Context

The game already knows the selected tile, living populations, current calendar, terrain resources,
scenario limits, and eligible interventions. The UI must derive targets and costs from that state
rather than asking for IDs or coordinates.

## Proposed Workflows

1. Start a run: choose unrestricted Sandbox, Locust Plague, or Drought Recovery.
2. Track challenge state: see time remaining, action points, objective progress, and final result.
3. Intervene in the locust challenge: select a tile and spend points to cull locusts, restore grass,
   or seed Meganeura.
4. Intervene in the drought challenge: select a stressed land tile and spend points to create
   watering holes, restore vegetation, or seed a temporary rain spell.

## Workflow Requirements

### 1. Start a run

- **Displayed:** mode name, description, challenge duration, action budget, and victory conditions.
- **Actions:** start Sandbox, Locust Plague, or Drought Recovery.
- **Empty state:** startup overlay remains visible and simulation stays paused until a mode is chosen.
- **Error state:** initialization failure is shown on the overlay without dismissing it.
- **Success feedback:** overlay closes, the selected scenario appears in the status panel, and time begins.

### 2. Track challenge state

- **Displayed:** scenario name, year/day progress, remaining action points, three objective states, and
  final victory/defeat message.
- **Actions:** pause/resume through existing controls, restart the current scenario, or return to scenario selection.
- **Empty state:** Sandbox explains that objectives and action limits are disabled.
- **Error state:** unavailable objective data is shown as an explicit unavailable state.
- **Success feedback:** objective values refresh immediately after ticks and interventions; the simulation
  pauses when the challenge resolves.

### 3. Intervene in the locust challenge

- **Displayed:** selected tile, eligible actions, point costs, and why any action is unavailable.
- **Actions:** cull 99% of locusts within two hexes (1 point), fully restore Graze pools within
  four hexes (2 points), or seed five Meganeura on the selected tile (3 points).
- **Empty state:** no tile selection shows guidance to select an affected land tile.
- **Error state:** inline feedback explains invalid terrain, missing targets, completed challenges, or
  insufficient points.
- **Success feedback:** tile values, action points, and objective progress refresh immediately with a
  concise confirmation message.

### 4. Intervene in the drought challenge

- **Displayed:** selected tile water and vegetation levels, current weather, eligible actions, costs,
  and unavailable reasons.
- **Actions:** create watering holes within three hexes (2 points), restore plant food pools within
  three hexes (2 points),
  or seed a 45-day global rain spell (3 points).
- **Empty state:** no tile selection explains that interventions are applied from a selected land tile.
- **Error state:** inline feedback explains invalid terrain, already-saturated resources, active rain,
  completed challenges, or insufficient points.
- **Success feedback:** resources, weather, action points, and objective progress refresh immediately
  with a concise confirmation message.
